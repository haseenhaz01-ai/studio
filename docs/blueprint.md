# **App Name**: FinCalc Pro

## Core Features:

- Vite Conversion: Convert the single-file React + Tailwind site to a production-ready Vite project with appropriate file structure and configurations.
- CSV Export: Implement functionality to export calculation results into CSV format.
- Shareable Scenario Links: Enable the generation of shareable links that encode the current state of the calculator, allowing users to share and reproduce specific scenarios.
- Currency Conversion Tool: An AI powered tool to convert currencies according to user-specified currencies, as well as intelligently identifying a users local currency based on the data present.

## Style Guidelines:

- Background color: Light gray (#F0F2F5), providing a clean and neutral backdrop for financial calculations.
- Primary color: Teal (#008080), conveying trust, stability, and growth in the financial context.
- Accent color: Yellow-gold (#FFD700) to highlight important figures, CTAs, and results.
- Body font: 'Inter', a sans-serif font for clear and accessible display of numerical data and text.
- Headline font: 'Space Grotesk', a sans-serif font for impactful section titles.
- Crisp, modern icons to represent different calculators and functions. Ensure icons are visually distinct and intuitive.
- Maintain a clean, well-organized layout for calculators to avoid visual clutter and ensure usability. Employ clear section dividers and labels.
- Subtle animations to transition between different calculator sections. Add smooth transitions for loading indicators during CSV export and chart rendering.
